⚙️ Configurações & Sincronização

Para atualizar em tempo real em 2 celulares diferentes simultaneamente no mercado sem servidor próprio, use o Firebase Realtime Database (gratuito e instantâneo).

📋 Passo a passo do Firebase (2 minutos)
  1. Acesse o Firebase Console (grátis com conta Google).
  2. Clique em Criar Projeto (ex: "MercadoLista").
  3. Vá em Criação > Realtime Database > Criar Banco de Dados (escolha modo de teste para permitir leitura/escrita).
  4. Nas configurações do projeto, copie o objeto firebaseConfig e cole abaixo.
